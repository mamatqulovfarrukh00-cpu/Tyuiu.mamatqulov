🌿 Tyuiu.mamatqulov — OOP Sprint Review Project
Данный репозиторий представляет собой учебный проект на языке C#, демонстрирующий практическое применение принципов объектно-ориентированного программирования (ООП). Проект состоит из 4 спринтов, каждый из которых раскрывает отдельную тему: от базового наследования до сложных обобщенных типов и фабричных паттернов. Все модули объединены в единое консольное приложение с удобным меню навигации.
Запуск проекта
Для запуска выполните следующие команды в терминале:
1.cd Tyuiu.mamatqulov
2.dotnet run
В открывшемся меню выберите номер спринта для демонстрации его работы.
📋 Описание спринтов
0️⃣ Спринт #0: Управление садом (Основы ООП)
Тема: Наследование и Полиморфизм.
Классы: Plant (базовый), Flower, Tree.
Реализация:
Создана иерархия классов растений с общими свойствами (Name, Type, Height).
Метод Цветение() переопределен (override) в классах-наследниках для демонстрации полиморфизма.
Реализованы методы роста (Растет) и старения (Вырастить).
Протестировано создание объектов и работа с массивом родительского типа.
1️⃣ Спринт #1: Инкапсуляция и Модификаторы доступа
Тема: Скрытие данных и управление доступом.
Классы: Product, Seller, Store.
Реализация:
Строгое использование модификаторов: private (name, price), protected (category, salary), internal (description).
Реализована логика продажи товаров через метод SellProduct, корректно изменяющий остаток на складе.
Метод GetTotalPrice вычисляет общую стоимость, а GetProductInfo возвращает полное описание товара.
Класс Store агрегирует продавцов и управляет списком товаров.
🏢 Спринт #2: Наследование и Интерфейсы
Тема: Иерархия классов и множественное поведение.
Классы: Employee → Manager → ProjectManager.
Интерфейсы: IReportable, ITeamLeader.
Реализация:
Построена трехуровневая иерархия сотрудников с расширением метода PrintInfo().
Решена задача множественного наследования через интерфейсы: проектный менеджер может генерировать отчеты (GenerateReport) и управлять командой (GetTeamMembers).
Продемонстрировано различие между простым наследованием и реализацией контрактов интерфейсов.
🖥️ Спринт #3: Полиморфизм и Generic классы
Тема: Абстракция, обобщенные типы и перегрузка операторов.
Классы: Component (абстрактный), CPU, RAM, GPU, HDD, Computer.
Реализация:
Создан абстрактный базовый класс Component и интерфейс IInstallable.
Перегружены операторы == и != для сравнения компонентов по цене.
Использованы Generic-методы AddComponent<T> и RemoveComponent<T> с ограничениями (where T : Component, IInstallable) для типобезопасной сборки ПК.
Реализован статический класс ComputerFactory для создания готовых конфигураций (Gaming/Office PC).
